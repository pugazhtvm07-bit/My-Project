02 parser / grok rules & manual ingest

Grok-style extraction rules

Each source has a dedicated pattern. A miss on the pattern (or a required field) routes straight to the dead-letter queue.

syslog · RFC3164
^<PRI>(MONTH\s+DAY\sTIME)\s(HOST)\s(PROCESS)(\[PID\])?:\s(MESSAGE)$
windows · event JSON
requires: EventID, Computer, TimeCreated, Level, Message
app_json · service log
requires: ts, level, service, msg
